# AGENTS.md — lead workspace (prospective project)

This workspace is a **prospective client project that has not been awarded.**
Codex's role here is to **assess, scope, and plan** — not to implement. It
mirrors `CLAUDE.md` in this folder; read that for the full contract.

## Stage rules

You may: analyze the brief in `brief/`, inspect supplied assets, inspect the
`wp-starter` starter **read-only**, record reusable starter capabilities,
recommend architecture, identify risks, propose success metrics, and prepare
scope/estimate material in `proposal/`.

You must not: modify the shared `wp-starter` repo, begin implementation, assume
the project is awarded, create credentials, initialize git, or promote
speculative requirements into confirmed scope.

Always label output as one of: confirmed requirement, assumption,
recommendation, or open question.

## Reading order

1. `brief/original-brief.md`, `brief/client-responses.md`
2. `references/wp-starter-context.md`
3. The real starter, read-only, only to verify a capability.

Promotion is handled by `wp-starter lead promote <slug>` — never convert this
workspace into an implementation repo by hand.
